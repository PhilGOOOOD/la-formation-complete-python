# Code en ville

Jeu en 3D pour réviser tout le Code de la route (permis B).

**Jouer : https://philgoood91.github.io/code-en-ville/** — ordinateur, tablette ou téléphone, sans compte. Installable comme une application (menu du navigateur → « Installer » / « Sur l’écran d’accueil ») et utilisable hors connexion.

- `index.html` : le jeu complet (moteur 3D, textures et polices intégrés).
- `sources-code-en-ville.zip` : le code source, les tests et la documentation technique.
